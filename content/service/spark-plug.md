# Совместимость свечей
> [!warning] Важно
> Стоковая свеча идет с резистором - об этом говорит буква R в названии модели! Применение свечей без резистора чревато проблемами с приборной панелью.

| Свеча       | Комментарий |
| ----------- | ----------- |
| Torch A7RTC | Стоковая    |
| NGK CR7HSA  | Аналог      |
| Torch A7RIU | Иридиевая   |

# Замена свечи зажигания
1. Отключаем разъем свечи на двигателе

> [!info]- Где разъем свечи - фото
> ![[spark-plug-where.jpg]]

2. Выкручиваем свечным ключом свечу
3. Закручиваем новую свечу
4. Подключаем разъем обратно
